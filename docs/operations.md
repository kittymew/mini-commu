# 운영 문서 준비

현재는 1단계이며 운영 가능한 서비스와 데이터가 없습니다. 실제 외부 Supabase 연결, DB·Storage 백업, 복원 실행, 자산 정리 작업은 수행하지 않았습니다.

후속 단계에서 추가할 내용:

- 2~3단계: 서버 전용 최초 운영자 설정, 최초 초대 발급, 권한 점검
- 5단계: 이미지 검증·변환 후 저장 한도, 임시 자산 정리 주기와 참조 보호
- 8단계: DB와 Storage 별도 백업·복원 절차, 실제 연결 및 실행 여부

회원의 PDF/JSON 내보내기는 서비스 복구용 백업을 대체하지 않습니다.
