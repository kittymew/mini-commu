# 7단계 · 회원 내보내기

모든 활성 회원은 메뉴의 **내보내기**(`/mini-commu/#/exports`)에서 열람 가능한 글을 저장할 수 있습니다. 운영자에게도 같은 콘텐츠 공개 범위를 적용합니다.

## 사용 방법

1. JSON 또는 PDF 인쇄를 선택합니다. 전체/카테고리, 시작일·종료일, 댓글·이미지 포함 여부를 지정합니다. 날짜는 서울 시간이며 종료일 당일까지 포함합니다. 빈 날짜는 해당 방향으로 제한하지 않습니다.
2. 파일당 글 수는 기본 200개, 1~200개입니다. 준비하면 작성 시각과 ID 기준으로 오래된 글부터 대상을 반복 조회합니다. 같은 시각의 글도 중복 없이 정렬합니다.
3. 준비된 파일을 다운로드하거나 PDF 인쇄 창에서 저장합니다. 다음 파일을 준비해 마지막 분할까지 반복합니다. 분할 선택기로 이전 파일도 다시 만들 수 있습니다.
4. 전체 글 수, 분할별 범위와 전달한 파일 수를 확인합니다. 앱은 다운로드 완료나 인쇄 창의 저장/취소를 알 수 없으므로 브라우저에서 실제 파일을 확인합니다. 같은 분할을 다시 전달해도 진행 수를 중복 계산하지 않습니다.

준비·다운로드 작업은 취소할 수 있습니다. 실패하면 해당 분할을 다시 준비하거나 선택을 초기화합니다. 이미지 합계가 분할당 64 MiB를 넘으면 중단하며 파일당 글 수를 줄이거나 이미지 포함을 해제하도록 안내합니다. 파일을 조용히 잘라 저장하지 않습니다. 텍스트·댓글·ZIP 처리도 브라우저 메모리를 사용하므로 큰 문서는 작은 단위로 나눕니다.

## JSON과 이미지 ZIP

이미지를 제외하면 들여쓰기된 UTF-8 JSON, 포함하면 `archive.json`, `README.txt`, `images/`의 실제 WebP 파일을 담은 ZIP을 받습니다. 파일명은 기준일과 분할 번호를 포함합니다. 이미지 경로는 ZIP 내부 상대경로이며 인증 URL이나 만료 서명 URL이 아닙니다. 인증한 Storage 요청으로 첨부 원본과 작성 당시 프로필 썸네일을 받아 보관합니다.

`schema_version: 1` 형식에는 내보낸 시각, 대상 기준 시각, 시간대, 선택 조건, 전체 글 수, 분할 번호/개수와 해당 글 수가 들어갑니다. 각 글에는 공개 콘텐츠 ID, 형식, 제목, 구조화 본문과 일반 텍스트, 작성/수정 시각, 공지, 카테고리, 작성자 스냅샷, 이미지, 선택한 댓글, 투표가 들어갑니다. 본문 문법은 [게시글 안내](posts.md)를 따릅니다.

댓글은 부모 ID와 작성 당시 이름/모습을 보존합니다. 삭제·숨김 부모 아래 공개 답글이 남으면 부모는 본문·작성자 없는 자리 표시만 남깁니다. 투표 설정·선택지는 공개하되 결과는 기존 공개 정책을 따르고, 공개 전에는 `results: null`입니다. 공개된 기명 결과만 당시 이름/모습과 선택지를 포함합니다. 익명 투표 참여자의 신원과 본인의 비공개 선택도 포함하지 않습니다.

이메일, 내부 소유 계정 ID, 초대 코드, 숨김/삭제 글, 삭제 댓글 본문, 비공개 투표 데이터, 초안, 운영 기록은 서버와 파일 생성 양쪽의 명시적 필드 목록에서 제외합니다. 이미지 제외 시 프로필 이미지도 제외합니다. 회원 파일은 서비스 복구용 백업이 아닙니다.

## PDF 인쇄

전용 미리보기는 Noto Sans KR 글꼴을 앱과 함께 제공하고, 이미지 디코딩과 글꼴 로딩 완료 후 버튼을 활성화합니다. 작성자 스냅샷, 서울 기준 시각, 본문, 첨부, 공개 투표 결과와 댓글을 출력합니다. 글은 오래된 순서이며 긴 본문은 페이지를 나누고 이미지 비율과 댓글 묶음을 유지합니다. 새 글은 새 페이지에서 시작합니다(첫 글은 표지 아래).

화면의 **PDF 인쇄 / 저장** 버튼으로 최신 권한을 확인한 뒤 인쇄합니다. 일반 Ctrl/Cmd+P만 사용하면 안내 문구를 출력합니다. A4, 브라우저 머리글·바닥글 끄기를 권장합니다.

- Chrome/Edge: 대상을 ‘PDF로 저장’으로 선택합니다.
- Firefox: 프린터에서 ‘PDF로 저장’을 선택합니다.
- macOS Safari: 시스템 인쇄 창의 PDF 메뉴에서 저장합니다.
- 모바일: 브라우저/운영체제의 인쇄·공유 PDF 항목을 사용하며, 지원하지 않으면 데스크톱에서 저장합니다.

버튼을 누른 횟수는 실제 PDF 저장 완료를 뜻하지 않습니다. 브라우저별 인쇄 UI가 다르며 실제 Safari·모바일 기기 확인은 후속 검증 대상입니다. 글꼴의 OFL과 ZIP 라이브러리의 MIT 라이선스는 `public/`에 함께 제공합니다.

## 일관성과 권한

`export_manifest`는 시작 시각 이후 작성 글을 제외하고 200개씩 커서를 조회합니다. 전체 수 변동, 중복 또는 누락을 발견하면 다시 선택하도록 실패 처리합니다. `export_batch`는 최대 200개 글을 허용하고 댓글을 SQL에서 집계하여 API 기본 행 수 제한에 잘리지 않게 합니다.

준비 완료 시와 파일 전달/인쇄 직전에 `validate_export`가 현재 활성 회원 여부와 콘텐츠 체크섬을 검사합니다. 글·댓글·투표 결과가 바뀌거나 숨겨지면 이전 파일 전달을 중단합니다. 로그아웃·계정 전환·정지·취소 시 요청과 이미지 Blob URL을 정리합니다.

전체 작업은 장시간 DB 트랜잭션 스냅샷이 아닙니다. 서로 다른 분할을 준비한 시점의 콘텐츠는 달라질 수 있으며, 마지막 서버 확인 직후의 변경이나 이미 저장한 파일을 회수할 수는 없습니다. 인쇄 창으로 전달된 내용도 저장자가 관리해야 합니다. 서비스 복구는 [DB·Storage 백업 절차](operations.md#dbstorage-백업과-복원)를 따릅니다.
